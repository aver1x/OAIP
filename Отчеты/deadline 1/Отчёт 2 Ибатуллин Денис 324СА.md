## Задание 2.

```mermaid
flowchart TD
    A([Начало]) --> B[/Ввести исходный и конечный узлы/]
    B --> C[Получить топологию и стоимости каналов из LSDB]
    C --> D["dist[source] = 0; для остальных dist = бесконечность; prev = пусто; visited = пусто"]
    D --> E{Есть непосещенные узлы?}
    E -- Нет --> G[/Вывести: маршрут не найден/]
    G --> Z([Конец])
    E -- Да --> F[Выбрать непосещенный узел u с минимальным dist]
    F --> H{"dist[u] = бесконечность?"}
    H -- Да --> G
    H -- Нет --> I{u = узел назначения?}
    I -- Да --> J[Восстановить маршрут по массиву prev]
    J --> K[/Вывести маршрут и его стоимость/]
    K --> L[Передать пакет по найденному маршруту]
    L --> Z
    I -- Нет --> M[Отметить u как посещенный]
    M --> N[Выбрать следующего соседа v узла u]
    N --> O{Есть непосещенный сосед v?}
    O -- Нет --> E
    O -- Да --> P["candidate = dist[u] + cost(u, v)"]
    P --> Q{"candidate < dist[v]?"}
    Q -- Да --> R["Обновить dist[v] и prev[v] = u"]
    Q -- Нет --> S["Оставить dist[v] и prev[v] без изменений"]
    R --> T[Перейти к следующему соседу]
    S --> T
    T --> N
```
